# i18n Phase 2a (웹 다국어) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 웹 UI를 영어 기본 + 한국어 전환 가능한 다국어로 전환한다 (스펙: `docs/superpowers/specs/2026-07-24-i18n-phase2a-web-design.md`).

**Architecture:** next-intl(쿠키 로케일, URL 무변경). 서버 컴포넌트 `app/layout.tsx`가 쿠키에서 로케일을 읽어 `<html lang>` + `NextIntlClientProvider`를 세팅, 클라이언트 컴포넌트는 `useTranslations()`로 소비. 문자열은 `messages/en.json`(기본)·`messages/ko.json`(기존 한국어 이전).

**Tech Stack:** Next.js 14.2 App Router, next-intl v3, TypeScript, pnpm 9 workspace.

## Global Constraints

- 작업 위치: 브랜치 `feat/i18n-phase2a` (main에서 분기). 단 저장소에 동시 세션이 있을 수 있으니 실행 시점에 controller가 브랜치/원장 상태를 확인한다.
- 지원 로케일 `['en','ko']`, 기본 `'en'`, 쿠키명 `dbflow_locale` — verbatim.
- 라이브러리 `next-intl`만 추가(다른 i18n 의존성 금지). 설치는 `pnpm --filter @dbflow/web add next-intl`.
- 각 태스크 종료 게이트: `pnpm --filter @dbflow/web build` 성공 + `pnpm --filter @dbflow/web exec tsc --noEmit` 통과.
- 문자열 이전 시 **의미 보존**: `ko.json`엔 기존 코드의 한국어를 그대로, `en.json`엔 동등한 영어. 도메인 용어는 기존 영문 enum·README와 정합(Change Request, Reviewer, Approver, Apply, Freeze, Rollback, Audit).
- `Asia/Seoul` 타임존(작업창·동결 판정)은 언어와 무관하게 유지 — 날짜 "표기 로케일"만 바꾼다.
- 기존 개발 워크플로(`start.sh`)·api·docker 무변경. 이 플랜은 `apps/web`만 건드린다.
- 커밋은 태스크별. web은 jest 미설정이므로 "테스트"는 build+tsc+대상 파일 한국어 잔존 grep(`grep -n '[가-힣]'`)으로 검증.

`apps/web/i18n/config.ts`:
```ts
export const locales = ['en', 'ko'] as const;
export type Locale = (typeof locales)[number];
export const defaultLocale: Locale = 'en';
export const LOCALE_COOKIE = 'dbflow_locale';

export function resolveLocale(value?: string | null): Locale {
  return (locales as readonly string[]).includes(value ?? '') ? (value as Locale) : defaultLocale;
}
```

`apps/web/i18n/request.ts`:
```ts
import { getRequestConfig } from 'next-intl/server';
import { cookies } from 'next/headers';
import { LOCALE_COOKIE, resolveLocale } from './config';

export default getRequestConfig(async () => {
  const locale = resolveLocale(cookies().get(LOCALE_COOKIE)?.value);
  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

- [ ] **Step 6: LocaleToggle**

`apps/web/components/locale-toggle.tsx` — `components/theme.tsx`의 `ThemeToggle`(radiogroup) 패턴을 참고해 작성:
```tsx
'use client';
import { useLocale } from 'next-intl';
import { useRouter } from 'next/navigation';
import { LOCALE_COOKIE } from '@/i18n/config';

const OPTIONS = [
  { value: 'en', label: 'EN' },
  { value: 'ko', label: '한' },
] as const;

export function LocaleToggle() {
  const locale = useLocale();
  const router = useRouter();
  const set = (v: string) => {
    document.cookie = `${LOCALE_COOKIE}=${v}; path=/; max-age=31536000`;
    router.refresh();
  };
  return (
    <div role="radiogroup" aria-label="Language" className="inline-flex rounded-md border border-gray-200 dark:border-gray-700 p-0.5">
      {OPTIONS.map((o) => (
        <button
          key={o.value}
          role="radio"
          aria-checked={locale === o.value}
          onClick={() => set(o.value)}
          className={`px-2 py-0.5 text-xs rounded ${locale === o.value ? 'bg-gray-200 dark:bg-gray-700 font-semibold' : 'text-gray-500'}`}
        >
          {o.label}
        </button>
      ))}
    </div>
  );
}
```
(구현자: 실제 className은 `theme.tsx`의 스타일과 톤을 맞춘다.)

```ts
const STRINGS: Record<string, { en: string; ko: string }> = {
  requestFailed: { en: 'Request failed.', ko: '요청에 실패했습니다.' },
  sessionExpired: { en: 'Your session has expired. Please sign in again.', ko: '세션이 만료되었습니다. 다시 로그인해 주세요.' },
  exportFailed: { en: 'Export failed.', ko: '내보내기에 실패했습니다.' },
  loginFailed: { en: 'Sign-in failed.', ko: '로그인에 실패했습니다.' },
};

function currentLocale() {
  if (typeof document === 'undefined') return 'en';
  const m = document.cookie.match(new RegExp(`${LOCALE_COOKIE}=([^;]+)`));
  return resolveLocale(m?.[1]);
}

export function ct(key: keyof typeof STRINGS): string {
  return STRINGS[key][currentLocale()];
}
```
